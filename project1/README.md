# Titanic Survival Prediction using Decision Tree Classifier

A machine learning project that predicts passenger survival on the Titanic based on socio-economic status, age, gender, and ticket details using a Decision Tree Classifier with scikit-learn.

## Project Overview
This project implements an end-to-end classification pipeline to estimate survival outcomes. It preprocesses numerical and categorical passenger attributes, handles missing values, trains a tuned Decision Tree Classifier, and evaluates prediction metrics (Accuracy, Precision, Recall, F1-Score).

## Files in Repository
- `project1/main.py`: The primary Python script for data preprocessing, model training, and evaluation.
- `project1/requirement.txt`: Lists all necessary Python packages and dependencies.
